# BRAND — демо-игры (прототип)

Прототип онлайн-лобби с девятью демо-играми. Только демомонеты, без денежной стоимости.

Статический сайт без сборки: открывается сразу после загрузки на GitHub Pages.

## Состав

| Файл | Что это |
|---|---|
| `index.html` | весь прототип: лобби, игры, стили и логика |
| `support.js` | движок, который отрисовывает страницу |
| `assets/` | картинки игр (109 файлов) |
| `.nojekyll` | говорит GitHub Pages не обрабатывать файлы |

## Как опубликовать

1. На github.com нажмите **New repository**, назовите, например, `brand-casino`, выберите **Public** и нажмите **Create repository**.
2. Нажмите **uploading an existing file** и перетащите содержимое архива (не саму папку, а то, что внутри).
   GitHub принимает до 100 файлов за раз, поэтому загрузите в два захода:
   сначала `index.html`, `support.js`, `README.md`, `.nojekyll` и папку `assets` — если GitHub откажет, перетащите `assets` отдельно вторым коммитом.
3. **Settings → Pages → Build and deployment**: Source — **Deploy from a branch**, Branch — **main**, папка **/ (root)**, **Save**.
4. Через 1–2 минуты сайт будет по адресу
   `https://ВАШ-ЛОГИН.github.io/brand-casino/`

### Через git (если установлен)

```bash
cd папка-с-файлами
git init
git add .
git commit -m "BRAND demo prototype"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/brand-casino.git
git push -u origin main
```

Затем шаг 3 выше.

## Важно

- Файл `.nojekyll` начинается с точки и в macOS/Windows может быть скрыт. Если он не загрузится, сайт всё равно, скорее всего, заработает.
- Баланс и прогресс хранятся в браузере игрока (localStorage) отдельно для каждого адреса сайта: на github.io баланс начнётся с 5 000.
- Шрифты подгружаются с Google Fonts, нужен интернет.
- Режим «реальных аккаунтов» (кнопки «Войти» / «Создать аккаунт») работает только если подключён свой сервер; без него всё играется в демо.
